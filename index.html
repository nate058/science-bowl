Science Bowl Reader

Buzz against other players

Type any name. If nobody is in that room yet, it is created for you.
or jump into an open room

Each question is read aloud on every player's device. The first person to buzz answers. A wrong answer locks that player out and the question continues for everyone else. Anyone can start, skip, or change the settings. The room stays open as long as anyone is in it.

Room
Press Start (or N). Each toss-up is read aloud and shown word by word. Buzz with Space whenever you know it, then type your answer and press Enter. For multiple choice, type the letter (W, X, Y, Z) or the answer itself.
Toss-ups are worth 4 points. A wrong answer while the question is still being read is an interrupt: −4. If the checker gets it wrong, use the override button. If the checker gets your answer wrong, use the button next to it.
